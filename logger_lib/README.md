# Библиотека журналирования (Logger)

Динамическая библиотека на C++17 для записи текстовых сообщений в файл
журнала с поддержкой уровней важности, и демонстрационное приложение.

## Структура репозитория

```
logger_lib/
├── include/
│   └── Logger.h        # публичный интерфейс библиотеки
├── src/
│   └── Logger.cpp       # реализация библиотеки
├── app/
│   ├── main.cpp           # консольное приложение
│   └── MessageQueue.h     # потокобезопасная очередь для передачи сообщений писателю
├── Makefile
├── .gitignore
└── README.md
```

## Возможности библиотеки

* Три уровня важности сообщений: `Debug`, `Info`, `Error`
  (`enum class LogLevel`).
* Инициализация принимает имя файла журнала и уровень важности
  по умолчанию.
* Сообщения с уровнем важности ниже уровня по умолчанию в журнал
  не записываются.
* В журнал сохраняются: время получения сообщения, уровень важности
  и текст сообщения.
* Уровень важности по умолчанию можно изменить после инициализации
  методом `setLevel()`.
* Ошибки открытия/записи файла журнала обрабатываются через
  исключение `std::runtime_error`.

## Пример использования библиотеки

```cpp
#include "Logger.h"

using namespace logging;

Logger logger("app.log", LogLevel::Info);
logger.log("Приложение запущено", LogLevel::Info);
logger.log("Это сообщение не запишется", LogLevel::Debug);

logger.setLevel(LogLevel::Debug);
logger.log("А теперь запишется", LogLevel::Debug);
```

## Демонстрационное приложение

Консольное приложение читает сообщения из stdin и пишет их в журнал.
Ввод разбирается основным потоком, а сама запись в файл происходит
в отдельном потоке — обмен между ними идёт через потокобезопасную
очередь (`app/MessageQueue.h`).

Запуск:

```bash
./bin/logger_demo <файл_журнала> [debug|info|error]
```

Второй аргумент (уровень по умолчанию) необязателен, по умолчанию `info`.

Формат вводимой строки: `[уровень] текст сообщения`. Уровень можно
не указывать — тогда сообщение пишется с текущим уровнем по умолчанию:

```
info сервис запущен
что-то пошло не так, но уровень не указан
error диск заполнен
```

Для выхода — `exit`, `quit` или Ctrl+D.

## Сборка (Ubuntu/Debian, компилятор gcc/g++)

```bash
make            # собрать библиотеку и демонстрационное приложение
make lib        # собрать только библиотеку (build/liblogger.so)
make app        # собрать только приложение (bin/logger_demo)
make clean      # удалить все файлы сборки и файл журнала
```

`make test` собирает приложение и запускает его с параметрами
`app.log info` — дальше можно вводить сообщения в консоли как описано
выше.

## Требования

* gcc/g++ с поддержкой C++17
* GNU Make
* Только стандартная библиотека C++ (STL), сторонние библиотеки
  не используются.
